# 결과 분석 시각화 대시보드 설계

## 목적

완료된 벤치마크의 실제 응답, 점수, 지연시간, 비용을 사용해 모델의 종합 성능과 선수관계 역량을 한 화면에서 비교한다. 소개 자료의 근거로 사용할 수 있도록 수치와 표본 수를 함께 표시하며 목업 데이터는 사용하지 않는다.

## 데이터 경계

- 기존 `benchmark_runs`, `run_models`, `run_items`, `model_responses`, `scores`, `questions`, `question_revisions`만 읽는다.
- 원본 결과를 수정하거나 별도 분석 테이블을 만들지 않는다.
- 서버에서 모델·지표·질문 목적·문항 단위 집계를 수행하고, 클라이언트에는 직렬화 가능한 숫자 배열만 전달한다.
- 종합점수는 `response_present`를 제외한 평가 지표의 모델별 단순 평균으로 정의한다. 완전 일치 여부는 별도 지표로 계속 표시한다.
- 데이터가 없는 차트는 0으로 꾸미지 않고 “분석 가능한 데이터 없음” 상태를 표시한다.

## 화면 구성

1. 모델 종합 순위: 종합점수, 정확성, 선수관계 핵심 지표, 평균 지연시간을 카드로 비교한다.
2. 종합점수 막대그래프: 모델별 종합점수와 표본 수를 표시한다.
3. 평가 지표 레이더: 선택한 모델들의 모든 평가 지표를 0~100 범위로 비교한다.
4. 지표별 그룹 막대그래프: 지표마다 모델 점수를 나란히 비교한다.
5. 선수관계 역량 그래프: 목표 개념 정확성, 선수 개념 식별, 관계 방향, 적용, 추론 사슬, 교과서 근거를 별도 비교한다.
6. 질문 목적별 성능: `questions.purpose`별 정확성을 비교한다.
7. 성능·효율 산점도: X축 평균 지연시간, Y축 종합점수, 점 크기는 응답 수로 표현한다. 비용이 있으면 툴팁에 표시한다.
8. 문항별 히트맵: 문항과 모델의 정확성 점수를 색상으로 표시해 취약 문항을 찾는다.
9. 점수 분포: 모델별 점수를 0~20, 20~40, 40~60, 60~80, 80~100 구간으로 나눈 누적 막대그래프를 제공한다.

## 상호작용과 접근성

- 모델 다중 선택과 지표 선택 필터를 제공한다.
- 차트 툴팁에는 백분율, 표본 수, 지연시간, 비용을 표시한다.
- 모든 차트에는 동일 데이터를 보여주는 기존 표 또는 접근 가능한 요약 텍스트가 함께 존재한다.
- 작은 화면에서는 차트가 가로 스크롤 없이 세로로 쌓이고, 히트맵만 내부 스크롤을 허용한다.
- 모델 색상은 화면 내 모든 차트에서 동일하게 유지한다.

## 구조

- `src/server/results/analytics.ts`: 데이터베이스 조회와 분석 데이터 조립.
- `src/components/results/result-analytics-dashboard.tsx`: 필터 상태와 Recharts 시각화.
- `src/app/results/[id]/page.tsx`: 실행 메타데이터를 조회하고 분석 컴포넌트에 전달.
- `src/app/globals.css`: 차트 카드, 필터, 범례, 히트맵, 반응형 레이아웃.

## 오류 및 진행 중 데이터

- `SCORING` 실행도 저장된 점수 범위에서 표시하되 진행 중임을 알린다.
- 숫자 변환이 불가능한 행은 분석 배열에서 제외한다.
- 모델이나 점수가 없으면 빈 상태를 표시하고 화면 전체를 실패시키지 않는다.

## 검증

- 집계 유틸리티 단위 테스트: 종합점수, 지표 행렬, 분포 구간, 결측치 처리.
- 화면 단위 테스트: 주요 그래프, 필터, 빈 상태, 실제 수치 표시.
- 통합 테스트: 완료된 실제 테스트 실행에서 모델·지표·목적·문항 분석 데이터가 반환되는지 확인.
- 전체 단위·통합 테스트, 타입 검사, 프로덕션 빌드, Docker 화면 응답을 검증한다.
