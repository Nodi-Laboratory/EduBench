# 교과서 기반 선수관계 AI 벤치마크의 문항 생성 및 평가 방법론

## 개요

본 벤치마크는 AI가 교과서의 개별 사실을 기억하는지보다, **목표 개념을 이해하는 데 필요한 선수개념을 식별하고 선수개념→목표 개념의 방향성 있는 관계를 문제 해결에 적용하는 능력**을 측정한다. 선수관계는 두 개념의 단순 동시 출현이 아니라 개념 A의 이해가 개념 B의 이해·적용에 필요한 A→B 의존관계이며, 학습 순서와 교육자료 배열의 핵심 요소로 연구되어 왔다([Pan et al., 2017](https://aclanthology.org/P17-1133/); [Roy et al., 2019](https://ojs.aaai.org/index.php/AAAI/article/view/5020)). 이에 따라 문항 생성과 채점은 모두 동일한 선수관계 정의와 교과서 근거를 공유한다.

## 1. 문항 생성 방식

문항 생성은 여러 문항이 하나의 검색 결과를 공유하지 않고, **문항 하나마다 `방향성 생성 → 관련 자료 검색 → 근거 기반 생성 → 구조 검증`을 독립적으로 수행**한다.

1. **방향성 생성:** 과목, 학년, 선택 교과서·단원, 질문 목적, 문항 형식, 난이도와 추가 지시를 바탕으로 목표 개념 검색어, 선수개념 검색어, 통합 검색어와 문항 방향을 JSON으로 만든다. 이 단계에서는 완성 문항을 생성하지 않으므로 문항마다 다른 검색 의도를 먼저 확보할 수 있다.
2. **문항별 벡터 검색:** 통합 검색어를 임베딩하고 사용자가 선택한 교과서와 단원 안에서 기본 10개 청크를 검색한다. 교과서 앞부분에 정의된 개념이 뒤의 설명에 필요한 경우를 보완하기 위해 같은 자료의 직전 청크도 함께 수집한다. 검색 질의, 후보 범위, 순위, 페이지·단원과 선택 청크는 문항별로 저장한다.
3. **근거 기반 생성:** 생성 모델은 검색된 근거와 문항 방향만 사용하여 문항, 모범답안, 허용답안, 선택지와 `benchmarkDesign` 청사진을 구조화된 JSON으로 생성한다. 청사진에는 목표 개념, 선수개념과 역할, 선수→목표 관계와 이유, 필수 추론 단계, 예상 실패 징후 및 근거 청크가 포함된다. 생성 temperature는 0으로 고정하여 출력 변동성을 줄인다.
4. **검증 및 등록:** 스키마와 문항 형식을 검사하고, 문항과 청사진이 인용한 모든 근거가 실제 검색 결과에 포함되는지 확인한다. 존재하지 않는 청크를 인용하거나 필수 구조가 누락된 결과는 데이터셋에 등록하지 않는다.

문항은 다음 다섯 과제 유형을 순환 배정하여 특정 발문에 편중되지 않도록 한다.

| 과제 유형 | 측정 내용 |
|---|---|
| 선수개념 적용 | 선수개념을 목표 개념의 판단 근거로 실제 사용할 수 있는가 |
| 누락 선수개념 진단 | 잘못된 풀이에서 빠진 사전지식이나 추론 단계를 찾는가 |
| 단원 간 전이 | 서로 다른 단원의 개념을 하나의 의존 사슬로 연결하는가 |
| 관계 방향 판별 | A→B와 B→A를 구분하고 필요 이유를 설명하는가 |
| 선수개념 사슬 완성 | 다단계 관계에서 누락된 연결을 복원하는가 |

난이도는 문장 길이나 지엽적 지식이 아니라 **인지적 요구량**으로 조절한다. ‘하’는 핵심 개념 하나와 직접 관계 하나를 한 단계로 적용하고, ‘중’은 두 개의 관련 개념 또는 중요 조건을 사용하여 상황 해석→개념 선택→결론의 최소 두 단계를 요구한다. ‘상’은 둘 이상의 선수개념, 복수 근거와 세 단계 이상의 연쇄 추론, 조건 변화 또는 관계 방향 판별을 요구한다. 따라서 어려운 표현만 사용한 문항을 고난도로 잘못 분류하는 문제를 줄일 수 있다.

## 2. 평가 및 채점 방식

평가는 **결정론적 지표와 루브릭 기반 LLM 채점**을 결합한다. 모든 응답에 `response_present`와 `exact_match`를 적용한다. 완전 일치는 한국어 유니코드, 대소문자, 공백과 문장 끝 문장부호를 정규화한 뒤 후보 응답이 모범답안 또는 허용답안과 같은지를 0 또는 1로 판정한다. 이는 단답형·객관식에는 유용하지만 개방형 답안의 의미적 동등성을 충분히 포착하지 못하므로 보조 지표로 사용한다.

선수관계 문항에는 아래 여섯 지표가 자동 추가된다. LLM 채점자는 모델 식별자를 보지 않고 문항, 모범답안, 허용답안, 문항 청사진, 교과서 근거와 후보 응답을 대조하여 각 지표를 0~1로 절대평가한다.

| 지표 | 1점 | 0.5점 | 0점 |
|---|---|---|---|
| 목표 개념 정확성 | 결론과 핵심 조건이 정확함 | 결론은 맞으나 조건 일부 누락 | 결론 또는 개념이 틀림 |
| 선수개념 식별 | 필요한 개념을 모두 식별·사용 | 일부만 식별 | 식별하지 못함 |
| 관계 방향 정확성 | 방향과 필요 이유가 정확함 | 방향은 맞으나 이유가 불완전 | 방향 반전 또는 단순 연관 진술 |
| 선수개념 적용 | 모든 관계를 판단 과정에 사용 | 일부만 적용 | 용어만 나열 |
| 추론 사슬 완결성 | 필수 단계를 모두 연결 | 핵심 중간 단계 하나 누락 | 근거 없이 결론만 제시 |
| 교과서 근거 충실성 | 핵심 주장이 교과서로 뒷받침됨 | 일부 근거가 약함 | 외부·무근거 주장이 결론을 좌우 |

채점은 temperature 0과 JSON 스키마를 사용하며 각 점수에 한국어 판단 이유와 참조 근거를 저장한다. 요청한 지표가 누락되면 해당 지표만 다시 채점하고, 모든 `응답×필수 지표` 조합이 저장되어야 실행이 완료된다. 채점 제공자·모델·요청 식별자도 함께 기록하므로 점수의 생성 경로를 감사할 수 있다. 그 결과 정답률뿐 아니라 “선수개념은 찾았으나 방향을 반대로 이해함”, “결론은 맞았으나 적용 과정이 없음”과 같은 실패 원인을 분리할 수 있다.

## 3. 기존 벤치마크와의 비교

| 사례 | 핵심 방식 | 본 벤치마크와의 관계 |
|---|---|---|
| [MMLU](https://arxiv.org/abs/2009.03300) | 57개 분야의 고정 객관식 정확도 | 넓은 지식 비교보다 선수관계라는 좁은 능력과 실패 원인 진단에 집중한다. |
| [BIG-bench](https://arxiv.org/abs/2206.04615) | 200개 이상의 다양한 과제 | 과제 다양성은 수용하되 다섯 유형을 동일한 선수관계 구성개념에 정렬한다. |
| [HELM](https://arxiv.org/abs/2211.09110) | 시나리오·복수 지표·투명한 보고 | 문항 조건, 모델 요청, 버전과 다중 지표를 함께 보존하는 원칙을 따른다. |
| [RAGAS](https://aclanthology.org/2024.eacl-demo.16/) | 검색과 근거 충실성의 분리 평가 | 문항마다 검색을 다시 수행하고 검색 기록과 생성 근거를 별도로 추적한다. |
| [MT-Bench](https://arxiv.org/abs/2306.05685) | 개방형 응답의 LLM-as-a-Judge 평가 | 확장성은 활용하되 모델명 비공개·고정 루브릭·근거 제시로 편향을 완화한다. |

MMLU식 단일 정확도와 달리 본 방식은 정답 도출 과정의 어느 단계가 실패했는지 설명할 수 있다. BIG-bench의 과제 다양성, HELM의 다중 지표와 투명성, RAGAS의 검색·생성 분리, MT-Bench의 의미 기반 자동 채점을 결합하되, 모든 요소를 국내 교과서의 선수관계 평가라는 단일 목적에 제한한다. 따라서 범용 능력 순위보다는 교육과정에 근거한 원인 진단에 적합하다.

## 4. 타당성 판단과 필수 검증

현재 설계는 생성 청사진과 채점 지표가 모두 선수관계의 식별·방향·적용·연쇄 추론을 기준으로 삼으므로 **내용 타당도와 구인 타당도를 논리적으로 뒷받침**한다. 문항별 검색 범위와 근거, 생성 요청·응답, 채점 이유를 보존하는 구조도 재현성과 감사 가능성을 높인다. 그러나 이는 설계 타당성에 대한 판단이며, 아직 경험적으로 검증된 표준검사라는 의미는 아니다.

정식 근거 자료로 사용하기 전에는 다음 검증이 필요하다.

- 교과 전문가 2인 이상이 목표·선수개념, 관계 방향, 답안과 난이도를 독립 판정하고 합의율을 산출한다.
- 사람 채점자 간 및 사람–LLM 간 일치도를 가중 κ 또는 Krippendorff의 α 등으로 보고한다.
- 실제 응답으로 문항 난이도, 문항–총점 상관과 모델 간 변별도를 분석한다.
- 반복 실행과 서로 다른 채점 모델의 교차평가로 점수 안정성을 확인한다.
- 문항별 검색, 직전 청크 보충, 청사진과 교과서 근거를 각각 제거한 실험으로 각 요소의 기여도를 검증한다.
- 문항 간 의미 중복과 원문 과다 복제를 검사하여 암기와 데이터 오염의 영향을 줄인다.

현재 한계는 문항이 합성 생성되고 검색기가 필요한 선수개념을 놓칠 수 있으며, LLM 생성·채점 편향이 남는다는 점이다. 다섯 과제 유형도 현재는 순환 배정되므로 실제 교육과정의 개념 분포를 그대로 대표하지 않는다. 따라서 점수는 “AI의 보편적 교육 능력”이 아니라 **선택된 교과서·문항·채점 프로필 안에서 관찰된 선수지식 연결 수행도**로 해석해야 한다. 위 검증에서 사람 평가와의 일치도와 문항 변별력이 확인될 경우, 본 시스템은 AI가 어느 선수개념 또는 관계 단계에서 실패했는지를 재현 가능하게 설명하는 전문 평가도구로 사용할 수 있다.
